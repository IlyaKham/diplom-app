## Фактическая проверка

Локальный образ и опубликованный образ по digest проверены отдельными запусками. Повторная проверка выполнена в Windows PowerShell 5.1, чтобы команды работали в пользовательском терминале.

- `/healthz`: HTTP 200 и `ok`.
- `/`: HTTP 200 и страница приложения.
- `/style.css`, `/app.js`: HTTP 200.
- `/version.json`: корректный JSON с версией `0.1.0`.
- Несуществующая страница: HTTP 404.
- `nginx -t`: конфигурация корректна.
- `id -u`: 101; запуск с `--read-only`, временным `/tmp`, без Linux capabilities.

Контейнеры проверки удалены после завершения. Для просмотра оставлен только `diplom-app-preview` с портом `127.0.0.1:18080`; он доступен локально на компьютере владельца. Команда остановки/удаления: `docker rm --force diplom-app-preview`.
